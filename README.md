# Sai Anil Kumar Deyyala: Portfolio

A static portfolio site made of plain HTML, CSS and JavaScript. There is no build step, so GitHub Pages can serve it as it is.

## Publish on GitHub Pages

1. Create a new public repository. Name it `<your-username>.github.io` to get the address `https://<your-username>.github.io`, or use any name for a project site.
2. Upload everything in this folder: `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In the repository, open **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait a minute or two. The site address appears at the top of the Pages settings.

## Before you publish

- **Résumé:** the download buttons point to `assets/Sai_Anil_Kumar_Resume.pdf`. That PDF includes your phone number, and anyone who visits the site can download it. Replace the file with a version without it if you prefer. Keep the same file name.
- **Social links:** the GitHub and LinkedIn links were taken from your résumé. Check they are the ones you want public.

## Customize

- **Colors:** both themes (dark and light) are CSS variables at the top of `style.css`.
- **Content:** every section is plain HTML in `index.html`. Edit the text directly.
- **Career bar:** the roles and dates for the "one bar per month" chart are in the `roles` list in `script.js`. The tenure text updates itself from the current date.
- **Hero pipeline:** the commands shown in the animated release console are the `cmds` list in `script.js`.

## Notes

- The animated console, request-rate charts and terminal output are illustrations, not live data. They are labelled that way on the page.
- The site respects the visitor's "reduce motion" setting. Animations are switched off for them.
- The chosen theme is remembered in the browser.
- Fonts (Unbounded, Geist and Geist Mono) load from Google Fonts. If they are blocked, the site falls back to system fonts.
